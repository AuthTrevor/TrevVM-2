# Contributing

Contributions are welcome when they improve:

- Reliability
- Documentation
- Accessibility
- Security
- Usability

## Before contributing

1. Read the repository README.
2. Read `SECURITY.md`.
3. Review the license.
4. Open an issue or discussion for substantial changes.
5. Never submit credentials, personal data, copyright-protected installers, or proprietary assets.

## Documentation changes

Prefer clear and reproducible instructions. Include:

- The affected file or feature
- Host assumptions
- Required privileges
- Network dependencies
- Testing performed
- Rollback steps

## Pull requests

A useful pull request includes:

- A concise summary
- Motivation for the change
- Testing performed
- Host and Docker environment details
- Notes about changed ports, privileges, downloads, persistence, or dependencies
- Screenshots or logs when useful
